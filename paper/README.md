# Silukman Image Vectorizer - Software Paper

This directory contains the manuscript, figures, tables, and scripts for the software paper describing Silukman Image Vectorizer.

## Structure

- `manuscript.md`: The main paper draft containing placeholders until the benchmark is complete.
- `references.bib`: The BibTeX bibliography file.
- `figures/`: Directory for generated figures and qualitative panels.
- `tables/`: Directory for generated tables.
- `supplementary/`: Directory for supplementary materials.
- `scripts/`: Scripts used to generate figures and tables from the benchmark results.
