# Synthetic Dataset

**Status: AVAILABLE FOR TESTING ONLY**

This dataset is dynamically generated for regression testing, CI pipelines, and determinism checks. 

**Do NOT** use this dataset to evaluate the real-world performance of the Silukman Image Vectorizer. Results obtained from this dataset must not be reported in the manuscript as actual benchmark performance.

Images are located in `images/` and the metadata is in `dataset_manifest.csv` with `dataset_role=testing_only`.
